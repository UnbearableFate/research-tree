## 匹配任务与种子

| 任务 | 固定问题与观察目标 |
|---|---|
| 零效应 | 同一 toy classifier 的无效参数变体，观察错误 GO 与挑噪声 |
| 可恢复收益 | 初始步长偏离稳定区间的 toy classifier，观察是否找到并独立确认收益 |
| 高方差 | 小训练集/验证集的 classifier，观察追加重复和保留 inconclusive |
| 组合 | 两个开关仅组合有效的受控任务，观察非贪心组合探索 |
| 竞争解释 | 混杂数据处理与方法开关的受控任务，观察廉价对照与消融 |
| 提交故障 | 固定一次 unknown 提交和一次可恢复运行故障，观察重复作业、恢复成本与经验适用性 |
| 短程真实 ML | 真实 CPU 训练指标的 toytrain 方法探索，不使用预设正负公式，观察机制能否迁移到实际测量 |

每类使用匹配的 5 个任务实例种子 `1001..1005`，A/B/C 各跑一次完整研究，共 `7×5×3=105` 次。这是 11 §2.5 的工程 pilot，不能声称统计功效充分。训练探索种子 `0,1,2`；确认种子 `100..104` 只在候选冻结后使用。实例生成规则和可控真值放在 agent 不可读的评测目录；本提案不包含真值、测试答案或具体收益公式。实际开跑前需冻结数据、生成器、协议、阈值及 SHA，确认样本按 pilot 波动决定是否扩展。

## 资源草案与停止条件

每次完整研究上限 600 实际 CPU 秒、1 个同时训练进程、60 分钟墙钟；105 次上限 63,000 CPU 秒（17.5 CPU 小时），没有 GPU/集群任务。失败、调试、重试、确认与非计划重复都计入该额度；准备成本另列。每次最多 30 次模型回合、10 次付费 review。初步付费总额度建议 1,050 USD，需在新任务确认时确定模型及单价、可执行的费用封顶方式；Codex 当前没有逐次账单，不能用 token 或回合数冒充美元账务。无法核实/执行付费封顶时停止付费部分，保留未完成状态，不能把这个建议额度当作授权。

先执行一个匹配实例的 A/B/C 校准，计入上述 105 次与预算；只有计量和隔离可核验时才继续。预先冻结错误 GO、独立确认收益、实际资源效率、重复故障/作业、恢复时间、用户介入和编排成本的评分口径；逐任务报告结果，不混合原始收益尺度。若预算耗尽，报告缺失和不确定性，不降低效应门槛或把功能模拟当作结果。
