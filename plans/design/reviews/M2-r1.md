**What holds up.** The core of M2 is in `shared/` and tested through production entry points: deterministic `outcome` from the primary effect (U01/U02 pass through `evaluate_experiment`), engineering failure yields no evaluation (U03), screening winners stop at `candidate_ready` and GO under `stage1_confirmed` needs an unseen confirmation of the same code (U04/U05, `CONFIRMATION_REUSED`), independence fields (U10), guardrails (U09), the append-only obligation ledger with fingerprint reopen, severity-only-up, `UNRESOLVED_DISAPPEARANCE` and user waiver (O01–O04), stall counting with `STALL_STRUCTURAL` and the human-report flag (T01/T02), NOT GO rewritten to "no active node + accounted report", inconclusive decisions requiring 缺失证据/下一实验, `selection_rationale` after two inconclusive results, `migrate_states`, schema v8 upgrade, accept-with-evidence and `first_unaccepted_task`. Both read-only allowlists include `obligations` and are pinned by a packaging test. The page shows outcome, disposition, stall, confirmation and open obligations.

**What is missing or wrong.** Disposition is recorded but not enforced: a `paused` or `retired` node can still receive experiments, runs and seed extensions. `decide(status=prunable)` silently forces `retired` without the reconsider condition that `decide_disposition` demands, and re-verifying silently reactivates, so the three dimensions are not independent as 06 §3 requires (an assessed+inconclusive+paused node cannot be expressed). Under the `screening` profile a project can reach GO with no confirmation, which 06 §2.4 reserves for `stage1_confirmed`; doc_library promises a disclaimer the interface never checks. Entering confirmation does not require `candidate_ready` (open obligations, failed guardrails and retired nodes are not checked), so O03 is only half covered. The stall thresholds exist only as DB defaults with no configuration key or writer. The Claude adapter's injected workflow still says 无提升→可消灭 and never mentions disposition, obligations or `note_findings`, while the Codex skill does; doc_library still contains three pre-M2 sentences that contradict the code.
