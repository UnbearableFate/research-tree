## 评审原文

Review of batch M8 (typed relations, exploration share, workflow benchmark).

**What is in place.** The shared core carries the design's relation kinds on the existing `rel_related` edges, derives `tested_by`, `supports` and `invalidates` instead of migrating the database, adds the `exploration` flag and `exploration_fraction` with a reservation-time check, and raises `REPEATED_DIRECTION` for a renamed retired direction and for repairs past the per-root-cause limit. The `relations` read method is in the shared allowlist and both adapters' routes, and the packaging test keeps them equal. Tests U06, U07 and U08 exist and go through production entry points. Rules, the Codex skill and the Claude workflow prompt describe the same contract. The benchmark tooling generates five hidden-truth scenarios and a scorer.

**Main problems.** The repeated-direction guard is opt-in: a node created without a `direction` is never compared with retired nodes, so the U07 behaviour can be skipped by omission. A direction retired without any evaluation, which the design allows for user-abandoned ideas, can never be proposed again because the guard demands `repairs` and `repairs` demands an evaluation. The two search parameters that make these guards strict can be loosened by the Leader through `update_project` without a user instruction, which the design forbids for thresholds. On the benchmark side, the confound scenario produces no spurious gain at the default learning rate, so it cannot measure the behaviour it is meant to test. The truth file is reachable from the agent's own environment through the variable the trainer reads. The scorer's database path is untested, and several metrics and one task type from design file 11 are missing. Two configuration keys the template requires are read by nothing.

**Smaller items.** The new error code is absent from design file 10 and the README, the Claude workflow prompt repeats a sentence, the SQL header and README still name old schema versions, derived `supports` edges ignore whether the evaluation still applies, duplicate relation pairs create duplicate edges, and the Codex skill omits the `selection_rationale` obligation the Claude prompt states.
